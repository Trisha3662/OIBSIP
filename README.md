# 💼 OIBSIP Internship Projects

This repository contains my Python-based projects completed as part of the Oasis Infobyte Internship Program.

---

## 🚀 Projects

### 1️⃣ BMI Calculator (Python GUI)
A simple desktop application that takes user input (height & weight), calculates BMI, and classifies it into categories like Underweight, Normal, Overweight, and Obese.

📁 Folder: `BMI_Calculator`

---

### 2️⃣ Password Generator (Python GUI)
A secure password generator that allows users to create strong passwords with customizable length and character options (uppercase, lowercase, digits, symbols).

📁 Folder: `Password_Generator`

---

### 3️⃣ Weather App (Python GUI)
A real-time weather application that fetches weather data using an API and displays temperature, humidity, wind speed, and conditions in a clean graphical interface.

📁 Folder: `Weather_App`
